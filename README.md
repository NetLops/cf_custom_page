# Cloudflare Custom Error Page

A professional, beautiful, and atmospheric custom error page for Cloudflare, featuring an interactive particle network background, 3D tilt effects, and a touch of humor.

Designed with ❤️ by NetLops.

## Features

- **Interactive Background**: A responsive particle network that reacts to cursor movement and repels particles on hover.
- **3D Card Effect**: The main error container tilts dynamically based on mouse position.
- **Glitch Effect**: Hovering over the error code triggers a sleek cyberpunk glitch animation.
- **Cloudflare Integration**: Fully supports Cloudflare's dynamic tokens (`::ERROR_CODE::`, `::RAY_ID::`, `::CLIENT_IP::`, `::GEO::`, `::ERROR_MESSAGE::`).
- **Humorous Fallbacks**: Randomly displays a witty joke on load to soften the blow of a server error.
- **Local Preview Mode**: Automatically populates Cloudflare tokens with dummy data if viewed locally, so you can test the design without deploying.
- **Zero Dependencies**: Pure HTML, CSS (vanilla), and JavaScript (vanilla canvas). No external libraries needed.
