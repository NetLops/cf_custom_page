# Quick Start Guide

## How to use this page in Cloudflare

1. Open your `index.html` file and copy all of its contents.
2. Log in to your Cloudflare Dashboard.
3. Select the domain you want to apply this to.
4. Go to **Rules** > **Custom Pages**.
5. Find the page you want to customize (e.g., "500 Class Errors").
6. Click **Custom Pages**.
7. Paste the copied HTML content into the provided text box.
8. Click **Publish** or **Save**.

## Testing Locally

Simply open `index.html` in your web browser. The script includes a fallback mechanism that automatically populates the `::TOKEN::` fields with mock data (like a fake Ray ID and IP address) so you can see exactly how it looks before deploying it to Cloudflare!
